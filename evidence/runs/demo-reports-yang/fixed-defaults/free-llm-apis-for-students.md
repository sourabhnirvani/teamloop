# Top 3 Free LLM APIs for Students

## 1. Google Gemini API (AISI free tier)
- Free tier includes a generous quota (Gemini 2.0 Flash / 1.5 Flash) plus higher rate limits for students on verified school accounts.
- Easy REST + SDK (Python, Node). Good for class projects, chatbots, RAG demos.
- Docs: https://ai.google.dev/gemini-api

## 2. OpenAI (via partnership free credits / Azure for Students)
- Direct OpenAI is paid, but OpenAI partners regularly offer free credits to students, and Azure for Students gives $100–$300 credits that cover OpenAI-model access.
- Best if the student is already working in Azure / GPT ecosystem.
- Docs: https://learn.microsoft.com/azure/ai-services/openai

## 3. Hugging Face Inference API (free tier)
- Free tier covers hosted open models (Llama, Mistral, Gemma, etc.) at modest rate limits.
- Great fit for students who care about open-weights or want to experiment with many models.
- Docs: https://huggingface.co/docs/api-inference
