# TeamLoop

**Your team's coding agents, working as one team.** A lead agent takes a goal, splits it into
tasks, and hands them to each teammate's own coding agent (Claude Code, Cursor, Codex) over MCP.
Each agent works on its own GitHub branch. The lead runs the tests, merges green work and reopens
anything that fails. People approve merges from their phones. Every step is traced in neatlogs,
and every commit has an Entire checkpoint that shows whose agent wrote it.

Built for **neatHack** (Oct 10–12, 2026) by @sourabhnirvani and @JrKrishh. All code was written
during the event. Some ideas come from our earlier private projects, but none of their code is here.
